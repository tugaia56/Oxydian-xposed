# Oxydian

## Compatibilità Tema

Oxydian è compatibile al 100% con il tema scuro. Il tema chiaro è supportato per l'interfaccia dell'app stessa, ma alcune mods che modificano l'aspetto di sistema (Stili Notifiche, Toast, Dialogo) sono pensate e testate solo per il tema scuro: con il sistema Android in chiaro restano disattivate automaticamente e l'aspetto stock di OOS viene lasciato invariato, invece di applicare uno stile pensato per lo scuro su una superficie chiara.

Per la migliore esperienza, usa Oxydian con il sistema Android in tema scuro.
